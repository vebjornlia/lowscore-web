Your own TRMNL

If you have a TRMNL (7.5 inch) or the DIY kit with the TRMNL firmware, it can show the board. It fetches a new picture every 15 minutes from 07:00 to 24:00 and sleeps at night, so the battery lasts longer.

  1. 1

    Make a board

    If you don't have one yet, make one. If you do, open its settings page.

  2. 2

    Install the TRMNL firmware

    Use TRMNL's web flasher, as described in TRMNL's guide for your own device. Lowscore is built for firmware version 1.8.17.

  3. 3

    Point the display here

    In the display's Wi-Fi setup you can change the server address (how). Use this one:

    https://tpihsdosbteytykcxxce.supabase.co/functions/v1/trmnl
  4. 4

    Add the display

    The display shows a QR code and a nine-character code, like ABC-DEF-GHJ. Scan the QR code with the phone you manage the board from and tap “Add the display”. Or type the code under Displays on the settings page. The board comes the next time the display wakes: press its button, or wait up to five minutes.

Good to know

  • The display gets its own key when it connects. Only someone who can see the code on its screen can add it to a flat: the address it shows in its Wi-Fi setup isn't enough.
  • Remove it on the settings page and it shows a new code the next time it wakes.
  • If the display gets stuck, hold its button for 15 seconds. Then set up its Wi-Fi and server address again. It shows a new code: type it under Displays, then remove its old entry.
  • Lowscore never sends commands that wipe the display's Wi-Fi setup.
  • TRMNL is a separate company. Lowscore isn't made by them and has no deal with them.
